# Portofolio dk

Halo! 👋 Saya **Dika Rahmat Fadillah**. Ini adalah website portofolio yang saya bangun menggunakan React dan Supabase, dilengkapi dengan admin dashboard.

**Live Demo:** [dk.com](https://dk.com)

---

## 🛠️ Tech Stack

- **ReactJS** - Frontend framework
- **Tailwind CSS** - Styling
- **Supabase** - Backend & database
- **Framer Motion** - Animasi
- **Material UI** - Komponen UI

---

## ⚡ Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/dikarahmat/Portofolio_dk.git
cd Portofolio_dk
npm install --legacy-peer-deps
```

### 2. Setup Environment
Buat file `.env` di root folder:
```env
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 3. Jalankan
```bash
npm run dev
```
